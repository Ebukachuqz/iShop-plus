# Evaluation reports

This directory contains public, reproducible summaries of iShop evaluations. It excludes raw audio, provider payloads, transcripts tied to individual recordings, credentials, and local file paths.

- [Streaming playback and widget stability](audio-playback-verification.md)
- [Unified Drake reasoning and Vision follow-ups](unified-followup-verification.md)
- [Groq multimodal provider switching and verification](groq-multimodal-verification.md)
- [Speech recognition and downstream shopping benchmark](speech-benchmark.md)

The evaluation framework and synthetic fixtures are available in the parent `evals/` directory. Private inputs and raw run artifacts remain excluded by `.gitignore`.
